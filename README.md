# Human or AI? Website

This is a simple HTML/CSS/JavaScript website for a class project about AI emotional support and human emotional responses.

## How to run

Open `index.html` in a browser.

## What it does

- Shows emotional prompts.
- Randomizes whether the AI response appears as Response A or Response B.
- Asks users to guess which response was AI-generated.
- Collects confidence, emotional preference, and optional reasoning.
- Saves responses in the browser using localStorage.
- Lets you download the collected browser data as a CSV.

## Important note

This version saves results only on the user's browser. If you want results from multiple people to collect in one shared database, connect the project to Firebase, Supabase, or another backend.
